# Expense Tracker

## Project Overview

Expense Tracker is a terminal-based application developed using Python and SQLite. It allows users to manage daily expenses by adding, viewing, searching, updating, and deleting records.

## Features

* Add Expense
* View All Expenses
* Search Expense
* Update Expense
* Delete Expense

## Technologies Used

* Python
* SQLite
* SQL
* GitHub

## Database Schema

### expenses

| Column       | Type                              |
| ------------ | --------------------------------- |
| id           | INTEGER PRIMARY KEY AUTOINCREMENT |
| amount       | REAL                              |
| category     | TEXT                              |
| description  | TEXT                              |
| expense_date | TEXT                              |

## How to Run

1. Open terminal
2. Navigate to the project folder
3. Run:

python main.py

## Sample Categories

* Food
* Shopping
* Transport
* Bills
* Entertainment
